# Hybrid Operating Model

## Overview
Combines elements of Centralized and Federated models. Core, enterprise-wide capabilities are managed centrally, while domain-specific capabilities are federated.

## Typical Allocation
- **Centralized**: Platform Engineering, Infrastructure, Core Master Data (MDM), Global Governance policies.
- **Federated**: Domain Data Products, specific AI Use Cases, domain analytics.

## Conclusion
This is the most common transition state for large enterprises moving toward a Data Mesh or fully domain-oriented architecture.

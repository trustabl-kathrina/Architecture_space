# Platform Operating Model

## Overview
Treating the internal platform as a product, with internal developers/domains as the customers.

## Core Tenets
- **Reduce Cognitive Load**: The platform abstracts away infrastructure complexity (e.g., Kubernetes, Kafka) so domain teams can focus on business logic.
- **Self-Service**: Capabilities are provisioned via APIs or Developer Portals, not via IT ticketing systems (ServiceNow).
- **Golden Paths**: The platform team provides opinionated, supported routes for building and deploying products. Deviating from the path is allowed, but unsupported.

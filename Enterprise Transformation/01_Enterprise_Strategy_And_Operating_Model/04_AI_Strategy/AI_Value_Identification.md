# AI Value Identification

## Overview
Framework for identifying where AI can generate the most impact across the enterprise value chain.

## Value Archetypes
1. **Operational Efficiency**: Automating document processing, accelerating software development (coding copilots).
2. **Customer Intimacy**: Hyper-personalized marketing, proactive customer service agents.
3. **Risk & Compliance**: Real-time fraud detection, automated contract analysis.
4. **Innovation**: Generative design for new physical or digital products.

## Measurement
Value must be tracked relentlessly. (See `10_Value_Realization` in the broader Strategy folder).

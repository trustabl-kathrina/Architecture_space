# Gap Analysis

## Overview
The systematic comparison of the Current State Assessment against the Future State Architecture to identify what needs to be built, bought, or changed.

## Types of Gaps
1. **Technology Gaps**: Missing platforms (e.g., no central Data Catalog, no ML Platform).
2. **Data Gaps**: Missing foundational data elements required for future AI use cases.
3. **Process Gaps**: Lack of automated CI/CD pipelines, absent data governance processes.
4. **Skills Gaps**: Shortage of Cloud Architects, Data Engineers, or AI specialists.

## Action Plan
Each gap becomes an initiative or epic that must be sequenced onto the Transformation Roadmap.

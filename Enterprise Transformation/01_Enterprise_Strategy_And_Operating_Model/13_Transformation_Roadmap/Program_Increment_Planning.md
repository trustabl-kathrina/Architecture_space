# Program Increment (PI) Planning

## Overview
Derived from SAFe (Scaled Agile Framework), PI Planning is the cadence-based mechanism for executing the transformation roadmap.

## Process
- **Cadence**: Typically every 10-12 weeks.
- **Alignment**: Brings together all business owners, platform teams, and domain engineering teams.
- **Outcome**: A committed set of objectives, identified dependencies, and a roadmap for the next increment.

## Value
Ensures that the high-level roadmap translates into synchronized, agile execution across the enterprise.

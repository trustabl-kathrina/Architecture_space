# Investment Prioritization

## Overview
How the enterprise decides which Data, AI, or Platform initiatives get funded when demand exceeds budget capacity.

## The Matrix
Initiatives are plotted on a 2x2 grid based on:
1. **Strategic Value & ROI** (High/Low)
2. **Effort & Risk** (High/Low)

## Decision Flow
- **High Value / Low Effort**: Quick Wins (Fund immediately).
- **High Value / High Effort**: Strategic Initiatives (Fund selectively, break into milestones).
- **Low Value / Low Effort**: Fill-ins (Fund if spare capacity exists).
- **Low Value / High Effort**: Avoid (Reject funding).

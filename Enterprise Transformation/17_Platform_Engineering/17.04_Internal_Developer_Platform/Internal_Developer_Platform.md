# Internal Developer Platform (IDP)

## Overview
An Internal Developer Platform (IDP) is a self-service layer that allows developers and data engineers to interact with their organization's underlying infrastructure independently, without needing deep knowledge of the infrastructure itself or raising IT tickets.

## Core Capabilities
- **Service Catalog**: A centralized registry of all microservices, data products, and APIs.
- **Golden Paths**: Pre-configured, compliant templates for deploying standard applications or pipelines.
- **Self-Service Provisioning**: Automated provisioning of databases, cloud resources, and environments.
- **Developer Portal**: The unified UI (e.g., Backstage) where developers interact with the IDP.
- **Scorecards & Tech Radar**: Visibility into system health, security vulnerabilities, and approved tools.

## Value Proposition
- Reduces cognitive load on engineering teams.
- Drastically shortens time-to-market.
- Enforces security and architecture standards by default ("secure by design").

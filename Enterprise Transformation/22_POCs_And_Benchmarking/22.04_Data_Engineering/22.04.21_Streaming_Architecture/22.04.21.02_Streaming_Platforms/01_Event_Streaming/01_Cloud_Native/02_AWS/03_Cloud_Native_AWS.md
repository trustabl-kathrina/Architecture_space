# AWS Cloud-Native Streaming

This section focuses on Amazon Web Services' native ecosystem for building scalable streaming pipelines. AWS provides a mix of serverless and managed cluster services.

## Sub-Domains
1. **Kinesis**: AWS's native serverless data streaming service (Data Streams and Firehose).
2. **MSK (Managed Streaming for Kafka)**: AWS's managed Apache Kafka offering.
3. **Managed Flink (Kinesis Data Analytics)**: Serverless Apache Flink for stateful processing.
4. **Reference Architecture**: AWS-specific architectural blueprints.

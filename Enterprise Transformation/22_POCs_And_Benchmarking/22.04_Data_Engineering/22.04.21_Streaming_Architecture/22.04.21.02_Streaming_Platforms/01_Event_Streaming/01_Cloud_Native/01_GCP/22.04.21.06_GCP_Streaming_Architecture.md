# GCP Streaming Architecture

This section focuses on Google Cloud Platform's native ecosystem for building scalable, serverless streaming pipelines.

## Sub-Domains
1. **Pub/Sub**: GCP's serverless message bus.
2. **Dataflow**: The managed runner for Apache Beam.
3. **PubSub to BigQuery**: Native ingestion paths without compute.
4. **Streaming Lakehouse**: GCP streaming into object storage (GCS) and BigLake.
5. **Event-Driven GCP**: Using Eventarc and Cloud Run for lightweight EDA.
6. **Real-Time AI Pipelines**: Streaming data directly into Vertex AI for real-time inference.

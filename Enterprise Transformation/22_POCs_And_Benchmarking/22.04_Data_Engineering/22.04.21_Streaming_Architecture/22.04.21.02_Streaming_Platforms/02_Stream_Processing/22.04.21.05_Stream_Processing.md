# Stream Processing Architecture

Stream processing involves the continuous, concurrent execution of logic applied to unbounded data sets. This section details the frameworks and patterns used to compute over streams in real-time.

## Sub-Domains
1. **Apache Flink**: The industry leader in stateful stream processing.
2. **Spark Structured Streaming**: Micro-batch processing engine, ideal for unified batch/stream workloads.
3. **Beam and Dataflow**: Google's unified programming model and managed runner.
4. **Stateful Processing**: Managing local state, RocksDB, and checkpointing.
5. **Windowing Strategies**: Tumbling, Sliding, Hopping, and Session windows.
6. **Complex Event Processing (CEP)**: Pattern matching over event streams.

# Stream Processing Platforms

This section covers the compute engines and frameworks that consume, transform, join, aggregate, and analyze unbounded event streams in real time.

## Sub-Domains

### 1. Cloud Native
Fully managed compute engines provided by major cloud vendors for real-time analytics.
*   **01_GCP**: Google Cloud Dataflow (Streaming Engine, Real-Time AI Pipelines).
*   **02_AWS**: Amazon Managed Service for Apache Flink.
*   **03_AZURE**: Azure Stream Analytics.

### 2. Other (Open Source & Frameworks)
Cross-platform and open-source stream processing engines and core programmatic concepts.
*   **01_Apache_Flink**: Stateful processing engine for continuous streaming.
*   **02_Spark_Structured_Streaming**: Micro-batching and unified batch/stream API.
*   **03_Apache_Beam**: Unified programming model across diverse runners.
*   **04_Kafka_Streams**: Native stream processing library embedded in the Kafka ecosystem.
*   **05_Complex_Event_Processing**: Pattern matching (CEP).
*   **06_Stateful_Processing**: Managing local state, RocksDB, and checkpointing.
*   **07_Windowing_Strategies**: Tumbling, sliding, and session windows.

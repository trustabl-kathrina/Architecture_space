# Enterprise Streaming Patterns

This section details reference blueprints for common enterprise streaming use cases, combining ingestion, processing, and serving into end-to-end patterns.

## Sub-Domains
1. **Customer360 Streaming**: Real-time unified customer profiles.
2. **Fraud Detection**: Low-latency anomaly detection.
3. **Telecom Event Streaming**: High-throughput CDR processing.
4. **Real-Time Recommendation**: Dynamic ML feature materialization.
5. **Streaming Data Products**: Curated event streams.
6. **AI-Ready Streaming Platforms**: Feeding LLMs and RAG architectures in real-time.

# Data Mesh and Streaming

Data Mesh is a socio-technical paradigm that shifts data management from a centralized monolith to decentralized, domain-oriented teams. Integrating real-time streaming into a Data Mesh architecture requires specific patterns.

## Sub-Domains
1. **Domain Event Architecture**: Modeling events based on bounded contexts.
2. **Event Products (Data Products)**: Treating streams as first-class data products.
3. **Federated Streaming**: Managing infrastructure across decentralized domains.
4. **Streaming Governance**: Global standards for schemas and security across the mesh.

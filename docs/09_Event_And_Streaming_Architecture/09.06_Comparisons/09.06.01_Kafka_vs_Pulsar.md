# Kafka vs Pulsar

## Summary

Both are distributed event streaming platforms. **Kafka** has the largest ecosystem and hiring pool. **Pulsar** separates compute (brokers) from storage (BookKeeper) for elastic scale and built-in multi-tenancy.

| Dimension | Apache Kafka | Apache Pulsar |
| --- | --- | --- |
| Architecture | Broker stores partitions | Broker + BookKeeper tier |
| Multi-tenancy | ACL + quotas | Native namespace isolation |
| Geo-replication | MirrorMaker / Cluster Link | Built-in replication |
| Protocol | Kafka native | Kafka + Pulsar + MQTT |
| Maturity / skills | Very high | Growing |
| Managed | MSK, Confluent, Redpanda | StreamNative, Kafka protocol on some clouds |

## Recommendation matrix

| Scenario | Prefer |
| --- | --- |
| Default enterprise standard | Kafka / MSK / Confluent |
| Strong multi-tenant SaaS platform | Pulsar |
| Unified messaging (queues + streams) | Pulsar |
| Existing Kafka ecosystem investment | Kafka |

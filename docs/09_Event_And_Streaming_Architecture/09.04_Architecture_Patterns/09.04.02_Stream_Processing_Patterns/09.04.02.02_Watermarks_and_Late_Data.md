# Watermarks and Late Data

## Summary

Watermarks track **event-time progress** in stream processors. They determine when windows may close and results emit.

For the full enterprise deep dive (IoT offline sync, idle partitions, allowed lateness), see the canonical reference:

**[Watermarks](../../09.05_Benchmarks/09.05.02_Watermarks.md)**

## Quick reference

| Policy | Behavior |
| --- | --- |
| Discard late events | Lowest cost; data loss |
| Allowed lateness | Re-emit updated window results |
| Side output | Route late events to audit/DLQ topic |

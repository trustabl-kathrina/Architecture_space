# Event Streaming Platforms

This section covers the core messaging and event broker technologies responsible for the ingestion, storage, and distribution of event streams.

## Sub-Domains

### 1. Cloud Native
Fully managed, serverless, or PaaS streaming brokers provided by major cloud vendors.
*   **01_GCP**: Google Cloud Pub/Sub, BigQuery Subscriptions.
*   **02_AWS**: Amazon Kinesis, Amazon MSK (Managed Streaming for Kafka).
*   **03_AZURE**: Azure Event Hubs.

### 2. Other (Open Source & Ecosystems)
Cross-platform and open-source messaging brokers.
*   **01_Kafka**: Deep dive into Apache Kafka, including Core Concepts, Partition Strategies, Replication, Schema Registry, and Connect.

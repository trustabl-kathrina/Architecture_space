# Canonical Entities

## Purpose

Define the maintainable inventory for **canonical entities**—enterprise business objects (Customer, Account, Product, etc.) stored in the **Semantic Registry** as Concepts with `kind=entity`.

**Schema:** [Semantic Registry Schema](../01.%20Foundation/11.%20Semantic%20Registry%20Schema.md).  
**Pilot list:** [TM Forum SID Pilot Slice](../01.%20Foundation/10.%20TM%20Forum%20SID%20Pilot%20Slice.md) (Tier A).  
**Draft inventory (DA-05):** [Canonical Entity Inventory](../01.%20Foundation/12.%20Canonical%20Entity%20Inventory.md).

## Scope

| In scope | Out of scope |
| --- | --- |
| Entity inventory attributes, identity, governance status | Physical table design |
| Mapping hooks to ontology classes and Business Catalog | Entity resolution algorithms (see 03. Entity Resolution — deferred) |
| Domain vs enterprise ownership | Industry reference model licensing |

## Definition

A **canonical entity** is a governed business object type with a single preferred meaning, stable URI, identity keys, and accountable owner. Instances may live in many systems; the entity type is defined once.

## Maintainable attributes

| Attribute | Required | Description |
| --- | --- | --- |
| `entity_id` | yes | Internal MCP identifier |
| `uri` | yes | Stable ontology class IRI |
| `preferred_name` | yes | Enterprise display name |
| `definition` | yes | Link or reference to Modeling / glossary definition (do not fork prose) |
| `identity_keys` | yes | Business keys that identify instances (logical) |
| `domain` | yes | Owning domain |
| `owner` / `steward` | yes | Accountable people/roles |
| `status` | yes | `draft` \| `review` \| `approved` \| `deprecated` |
| `parent_entity_uri` | no | Specialization hierarchy |
| `synonyms` | no | Aliases for search (not alternate truths) |
| `version` | yes | Publication version |
| `effective_from` | yes | When this version became active |
| `replaced_by` | no | URI when deprecated |

## Governance statuses

```text
draft → review → approved → deprecated
                ↘ (reject back to draft)
```

| Status | Meaning |
| --- | --- |
| `draft` | Work in progress; not consumable |
| `review` | Submitted for steward / COE approval |
| `approved` | Published; eligible for mappings and product binding |
| `deprecated` | Still resolvable; new bindings forbidden; `replaced_by` required when successor exists |

## Relationships to other inventory

- **Concepts** — entities are a primary kind of concept; see [Concepts](02.%20Concepts.md)
- **Relationships** — typed links between entities; see [Semantic Relationships](04.%20Semantic%20Relationships.md)
- **Business Catalog** — business entity entries map via [Business Mapping](../05.%20Enterprise%20Mapping/01.%20Business%20Mapping.md)
- **Ontology** — published as **Apache Ossie** model elements (stable IDs); see [Ontology](../02.%20Ontology/01.%20Ontology.md) and [Apache Ossie](../02.%20Ontology/08.%20Apache%20Ossie.md)

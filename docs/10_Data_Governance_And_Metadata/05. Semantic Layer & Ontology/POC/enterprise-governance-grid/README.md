# Enterprise Governance Grid

Architecture showcase website for the **Enterprise Semantic Control Plane** concept (Semantic Layer & Ontology).

## Stack

- Vite 8 + React 19 + TypeScript
- Tailwind CSS 4
- Framer Motion

## Run

```bash
cd POC/enterprise-governance-grid
npm install
npm run dev
```

## Build / preview

```bash
npm run build
npm run preview
```

Static output lands in `dist/` and can be published to any static host.

## Content source

Derived from `05. Semantic Layer & Ontology` foundation docs: Vision, Architecture, SoR, Federation, Mapping, Governance, APIs, Roadmap.

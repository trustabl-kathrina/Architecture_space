# Setup And Run

## Prerequisites

- Docker Desktop (or Docker Engine + Compose v2)
- Ports **7474** (HTTP) and **7687** (Bolt) free

## Start Neo4j

```bash
cd POC/neo4j-contracts-kg
docker compose up -d
docker compose ps
```

Wait until health is healthy (≈30–60s on first pull).

## Load the Contracts graph

```bash
chmod +x scripts/*.sh   # once
./scripts/load.sh
```

Credentials (compose default):

| | |
| --- | --- |
| User | `neo4j` |
| Password | `contracts-kg` |
| Browser | http://localhost:7474 |
| Bolt | `bolt://localhost:7687` |

## Demo queries

1. Open Neo4j Browser → connect with credentials above.
2. Paste queries from [`../cypher/06-queries-demo.cypher`](../cypher/06-queries-demo.cypher) one section at a time.

Suggested first query:

```cypher
MATCH (c:Concept {conceptId: 'customer'})
OPTIONAL MATCH (c)<-[r]-(src)
RETURN c, r, src
LIMIT 50;
```

## Reset

Wipe nodes and reload seed (constraints kept):

```bash
./scripts/reset.sh
```

## Stop / destroy

```bash
docker compose down          # keep volume
docker compose down -v       # delete graph data volume
```

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| `load.sh` times out | `docker compose logs -f neo4j` — wait for “Started” |
| Auth failed | Password must match `NEO4J_AUTH` on first volume create; use `down -v` then `up` if you changed it |
| Port in use | Stop other Neo4j, or change host ports in `docker-compose.yml` |

## Optional: cypher-shell from host

If you have Neo4j tools installed locally:

```bash
cypher-shell -a bolt://localhost:7687 -u neo4j -p contracts-kg -f cypher/06-queries-demo.cypher
```

(Prefer Browser for multi-statement demo files.)

# Mapping Examples (TM Forum)

Business, technical, and product crosswalks targeting SID concepts in `global`.

Data: `tmforum.json` → `businessMappings`, `technicalMappings`, `productBindings`.

## Business (`mapsTo`)

| Source (Collibra DE) | → | SID target |
| --- | --- | --- |
| Kunde | mapsTo | Customer |
| Kundenkonto | mapsTo | Customer Account |
| Produkt | mapsTo | Product |
| Angebot | mapsTo | Product Offering |
| Dienst | mapsTo | Customer Facing Service |
| Auftrag | mapsTo | Product Order |

## Technical (`represents`)

| Asset | → | SID target |
| --- | --- | --- |
| crm.customer | represents | Customer |
| billing.account | represents | Customer Account |
| prod.product_instance | represents | Product |
| svc.cfs_instance | represents | Customer Facing Service |
| ord.product_order | represents | Product Order |

## Product (`implements`)

| Marketplace product | Implements |
| --- | --- |
| global-customer-360 | Customer, Customer Account |
| natco-de-kunden-360 | Customer, Customer Account (+ optional Kunden) |

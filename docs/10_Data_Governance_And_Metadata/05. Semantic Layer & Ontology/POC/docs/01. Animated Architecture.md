# Interactive Control Plane Architecture

Click any component on the site (`#architecture`) to explore dependencies and flow.

## Interaction model

| Highlight | Meaning |
| --- | --- |
| Teal ring | **Selected** component |
| Brass | **Depends on** (upstream inputs) |
| Signal / cyan | **What next** (downstream outputs) |
| Dimmed | Not in this component’s immediate graph |

## Side panel

1. Summary of the selected component  
2. **Depends on** — clickable upstream list  
3. **What next** — ordered downstream flow  
4. **Suggested path** — auto chain following first `next` edge

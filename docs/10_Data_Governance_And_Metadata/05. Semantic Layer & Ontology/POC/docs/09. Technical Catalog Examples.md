# Technical Catalog Examples — Multi-NATCO Customer

Technical catalog sources for **DE / AT / HR / HU / PL** plus the curated hub. Each source **represents** its local NATCO concept **and** TM Forum SID `global/Customer`.

## Start here

Machine inventory: [`../examples/technical-catalog-assets.json`](../examples/technical-catalog-assets.json)  
Full cross-pack inventory: [`../examples/multi-natco-customer-assets.json`](../examples/multi-natco-customer-assets.json)

## Sources (NATCO)

| NATCO | Table | ID column | represents (global) |
| --- | --- | --- | --- |
| natco-de | `crm_de.public.kunde` | `kundennummer` | `global/Customer` |
| natco-at | `crm_at.dbo.Kunde` | `kunden_id` | `global/Customer` |
| natco-hr | `crm_hr.public.kupac` | `kupac_id` | `global/Customer` |
| natco-hu | `crm_hu.dbo.Ugyfel` | `ugyfel_azonosito` | `global/Customer` |
| natco-pl | `crm_pl.public.klient` | `id_klienta` | `global/Customer` |

## Hub (global)

| Asset | Role |
| --- | --- |
| `c360_customer_build` | Pipeline — inputs = all five NATCO tables |
| `dp.curated.customer_360` | Curated Customer 360 table |
| `customer_id` | PK column → `CustomerIdentification` |

## Discovery steps

| Step | Action |
| --- | --- |
| 1 | Pick a NATCO table in the inventory |
| 2 | Follow `represents_local` → NATCO concept |
| 3 | Follow `represents` → `global/Customer` |
| 4 | Follow `feeds` → pipeline → curated hub |
| 5 | Open Context Graph / Neo4j country view (E1–E5) |

Markdown contracts under [`contracts/technical/`](contracts/technical/) remain useful for deeper Collibra-style examples; the JSON inventory above is the multi-NATCO machine source of truth for this POC.

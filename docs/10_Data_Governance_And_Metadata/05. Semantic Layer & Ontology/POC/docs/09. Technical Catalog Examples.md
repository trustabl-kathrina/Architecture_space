# Technical Catalog Examples — Customer Domain

Step-by-step **technical catalog** assets for the Customer POC. Catalog SoR = Collibra / Dataplex. Control Plane stores `represents` mappings to TM Forum SID concepts.

## Step-by-step discovery

| Step | Action | Result |
| --- | --- | --- |
| 1 | List NATCO-DE source tables in Collibra / Dataplex | `crm.customer`, `billing.account`, `cust.customer`, … |
| 2 | Open table contract | Schema, owner, grain, catalog `source_id` |
| 3 | Follow **columns** links | Per-column contracts (PK, PII, `represents`) |
| 4 | Follow **feeds** / **producedBy** | Pipeline + topic + OpenLineage |
| 5 | Follow **semantics** | SID concept URIs (`global/customer`, …) |
| 6 | Open curated hub | [`dp.customer_360`](contracts/technical/tables/dp.customer_360.md) |

# Governance Examples (TM Forum)

Lifecycle applied to SID-seeded concepts.

Data: `tmforum.json` → `governanceExample`.

## Customer (SID) state path

| State | Actor | Action |
| --- | --- | --- |
| draft | Data Architecture | Import SID Customer via import-tmforum → global stub |
| review | Global Customer steward | Submit with sid_domain / sid_abe annotations |
| approved | Global Semantic Council | Valid target for maps + hard product gates |
| deprecated | COE | Requires replaced_by + NATCO notify (5 business days) |

**Rule:** Only `approved` SID concepts may be active mapping / product-bind targets (POL-SEM-02).

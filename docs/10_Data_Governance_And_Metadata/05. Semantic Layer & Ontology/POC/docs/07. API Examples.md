# API Examples (TM Forum)

Headless calls using SID Customer / Product / CFS as the worked example.

Data: `tmforum.json` → `apiExamples`.

| API | Call | Result |
| --- | --- | --- |
| Semantic | `GET /concepts/global/customer` | SID Customer definition |
| Semantic | `POST /resolve { term: 'Kunde', natco: 'de' }` | → global/customer via sameAs |
| Graph | `GET /graph/neighbors/global/customer?depth=2` | Account · Product · CFS |
| Search | `GET /search?q=ProductOffering&ns=global` | Offering + Collibra Angebot |
| MCP | `semantic.lookup('customer-facing-service')` | Certified CFS URI for agents |
| Ossie | `GET /ossie/global/versions/1.0.0` | Tier A SID package export |

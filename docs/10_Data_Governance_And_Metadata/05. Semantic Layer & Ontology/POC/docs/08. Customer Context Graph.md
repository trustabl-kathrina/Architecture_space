# Customer Domain Context Graph

Traversable **knowledge / context graph** for the Customer domain — inspired by the OpenMetadata “Context Graph: From Raw Metadata to AI-Ready Meaning” pattern, grounded in **TM Forum SID** naming.

## Machine sources

| File | Role |
| --- | --- |
| [`../examples/customer-context-graph.json`](../examples/customer-context-graph.json) | Nodes, edges, predicate catalog |
| [`../examples/customer-contracts.json`](../examples/customer-contracts.json) | Detailed contracts for every node |

## Layers in the graph

| Layer | Examples |
| --- | --- |
| Technical catalog | `crm.customer`, `billing.account`, `dp.customer_360`, columns, pipeline, tests, Kafka topic, OpenLineage |
| Business catalog (multi-NATCO) | DE **Kunde**, TR **Müşteri**, UK **Customer** |
| Global semantics (TM Forum) | `Customer`, `Customer Account`, `Customer Identifier` |
| NATCO semantics | `Kunden` —sameAs→ `Customer` |
| Data products | `global-customer-360`, `natco-de-kunden-360` |
| Governance | PII classification, POL-PII-MASK-01, ODCS contract |
| Consumption | Revenue dashboard, ARPU, REST port |
| AI / Memory | Copilot, conversation, memory nugget |

```text
Dashboard           ──dependsOn───────────> Table
Metric              ──definedBy───────────> Glossary Term / Concept
Pipeline            ──produces────────────> Table

Policy              ──governs─────────────> Classification

OpenLineage Event   ──updatesLineageFor───> Pipeline
Glossary (NATCO)    ──mapsTo──────────────> SID Concept
NATCO Concept       ──sameAs──────────────> SID Customer
Product             ──implements──────────> SID Concept
Agent Conversation  ──capturedAs──────────> Memory
Memory              ──informs─────────────> Data Product
Memory              ──documentsDecisionFor> Metric
Memory              ──attachedTo──────────> Table / Column / Topic / Dashboard / Pipeline / API
```

## How to traverse (site)

1. Open **Context Graph** on the Enterprise Governance Grid site.
2. Click any node (start at **Customer 360 table** or **Customer** SID concept).
3. Inspector shows contract detail + neighbor edges.
4. Click a neighbor to walk the graph; use **Focus neighborhood** to dim non-adjacent nodes.

# Knowledge Graph Examples (TM Forum)

Context graph over SID pilot entities — not a second SoR.

Data: `tmforum.json` → `ontologyEdges`, `graphWalk`.

## Core SID walk

```text
Party —plays→ PartyRole
Customer —specializes→ PartyRole
Customer —owns→ CustomerAccount
Customer —obtains→ Product
Product —basedOn→ ProductOffering
ProductOffering —specifiedBy→ ProductSpecification
Product —realizedAs→ CustomerFacingService
```

## Crosswalk edges on the same graph

```text
Kunden —sameAs→ Customer
crm.customer —represents→ Customer
global-customer-360 —implements→ Customer
```

Impact example: deprecating `global/product` blast-radius includes CFS realizations, offering specs, and Marketplace binds.

# Technical Catalog Asset Inventory

Step-by-step inventory of **technical catalog** assets for the Customer-domain POC.
Each asset has a **linkable contract**. Catalog SoR remains Collibra / Dataplex; Control Plane holds `represents` mappings.

Machine source: [`../../../examples/technical-catalog-assets.json`](../../../examples/technical-catalog-assets.json)

## How to use

1. Find the asset in the table below.
2. Open its contract (stable `contract_id` + markdown link).
3. Follow **Linked assets** inside the contract to traverse tables → columns → pipeline → tests → semantics.

# Namespace & Federation Examples (TM Forum)

Namespaces and NATCO→global federation for the Customer 360 CEE set.

Data: `tmforum.json` → `federation` · inventory: [`examples/multi-natco-customer-assets.json`](../examples/multi-natco-customer-assets.json)

## Namespaces

| Namespace | Role | Naming |
| --- | --- | --- |
| `global` | Enterprise meaning SoR | TM Forum SID PascalCase (`Customer`, `CustomerIdentification`) |
| `natco-de` | Germany | `kunde` / `kundennummer` |
| `natco-at` | Austria | `kunde` / `kunden_id` |
| `natco-hr` | Croatia | `kupac` / `kupac_id` |
| `natco-hu` | Hungary | `ugyfel` / `ugyfel_azonosito` |
| `natco-pl` | Poland | `klient` / `id_klienta` |

Each NATCO namespace **ALIGNS_TO** `global` (federation, not inheritance).

## Federation edges (Customer)

| From (NATCO) | Predicate | To (SID global) |
| --- | --- | --- |
| natco-de/kunde | sameAs | global/Customer |
| natco-at/kunde | sameAs | global/Customer |
| natco-hr/kupac | sameAs | global/Customer |
| natco-hu/ugyfel | sameAs | global/Customer |
| natco-pl/klient | sameAs | global/Customer |
| */{local-id} | sameAs | global/CustomerIdentification |

### Resolve path example

```text
"Kupac" (Collibra HR)
  → mapsTo → global/Customer (SID)
  → sameAs ← natco-hr/kupac
  → CRM crm_hr.public.kupac represents both local + global
  → Customer 360 product implements global/Customer
```

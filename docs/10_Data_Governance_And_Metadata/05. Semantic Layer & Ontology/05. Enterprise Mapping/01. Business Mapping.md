# Business Mapping

## Purpose

Define the crosswalk from **Business Catalog** artifacts to **Semantic Control Plane** concepts—used to **enrich NATCO namespaces**. All NATCOs use **Collibra** as the business catalogue today.

**Canonical contract (DA-08):** [Mapping Contracts](../01.%20Foundation/15.%20Mapping%20Contracts.md) § DA-08.

## Scope

| In scope | Out of scope |
| --- | --- |
| Collibra → NATCO / global concept mapping | Replacing Collibra UI |
| Preference to reuse global concepts | Duplicating Collibra prose into Entropy |

## Platform decision

| Concern | System of record |
| --- | --- |
| Business glossary / KPI / entity approval | **Collibra** (every NATCO) — federated |
| Enterprise concepts | **Semantic Control Plane** (Semantic Registry) |
| Crosswalk records | **Mapping Engine** |
| Product-facing UX | Entropy Marketplace |

Federation: [Multi-NATCO Federation](../01.%20Foundation/07.%20Multi-NATCO%20Federation.md) · Architecture: [Architecture](../01.%20Foundation/05.%20Architecture.md).

## Definition

A **business mapping** binds a Collibra Business Catalog entry to one primary concept IRI (and optional secondary URIs), typically enriching the **NATCO** namespace and relating it to **global**.

## Enrichment flow (NATCO)

1. Term / KPI / business entity reaches `approved` in Collibra.  
2. NATCO steward searches **global** for an existing concept.  
3. If found: map Collibra entry → global concept (`exact` / `sameAs`) **or** create NATCO concept with `sameAs`/`specializes` → global.  
4. If not found: propose global extension (Global Council) **or** create NATCO-local concept (`scope=natco`).  
5. Mapping activated; Entropy concept metadata updated; audit in Collibra + Entropy.

## Schema

| Field | Required | Description |
| --- | --- | --- |
| `mapping_id` | yes | Internal identifier |
| `source_id` | yes | Collibra asset / term ID |
| `source_system` | yes | `collibra` |
| `source_type` | yes | `glossary_term` \| `kpi` \| `business_entity` |
| `natco_code` | yes | Owning NATCO |
| `target_uri` | yes | Entropy concept IRI (`global/…` or `natco-…/…`) |
| `target_namespace` | yes | `global` \| `natco-{code}` |
| `mapping_type` | yes | `exact` \| `close` \| `broad` \| `narrow` \| `related` |
| `global_link_predicate` | no | `sameAs` \| `specializes` \| `implements` \| `extends` when NATCO concept links to global |
| `confidence` | yes | Steward-asserted vs suggested |
| `owner` | yes | NATCO steward |
| `status` | yes | `draft` \| `active` \| `deprecated` |
| `effective_from` | yes | Active-from timestamp |
| `version` | yes | Mapping version |
| `notes` | no | Rationale |

## Cardinality rules

| Rule | Detail |
| --- | --- |
| Prefer global | Do not create a NATCO twin if `sameAs` to global suffices |
| Primary link | Each approved Collibra entry in scope has **exactly one** `exact` active mapping |
| KPI → metric | Map to Entropy Metric concepts (global preferred) |
| Synonyms | Multiple Collibra terms may `close`/`related` map to one concept |

## System of record

- **Definition prose / approval:** Collibra  
- **Concepts:** Semantic Control Plane (Registry)  
- **This crosswalk:** Mapping Engine

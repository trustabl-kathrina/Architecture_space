Home for the **Enterprise Semantic Control Plane** inside the Metadata Control Plane (MCP): headless SoR for enterprise meaning, crosswalks, knowledge graph, APIs, and Apache OSSIE exchange.

## Purpose

This section owns:

| Owns | Does not own |
| --- | --- |
| **Enterprise meaning** (Semantic Control Plane) | Business glossary prose (Collibra / Dataplex) |
| Semantic Registry, namespaces, ontology, KG | Technical metadata inventory (catalogs) |
| Mapping / federation / governance engines | **Data products** (Entropy Marketplace) |
| Semantic / Graph / Search APIs + MCP Server | First-party semantics UI (Marketplace is UI) |
| Apache OSSIE package exchange | Replacing BI semantic layers |

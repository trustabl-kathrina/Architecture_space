# Data Products Contracts

Asset-type contracts for **Data Products** spanning Collibra Data Product Catalog and **Entropy Marketplace** (product SoR).

| Asset type | Role |
| --- | --- |
| Data Product | Product identity & lifecycle |
| Data Product Port | Abstract port |
| Data Product Output Port | Consumer-facing interface |
| Data Product Input Port | Source interface |
| Data Contract | ODCS (preferred) commitments |
| Contract Field | Manifest schema property |

Control Plane binds meaning via **DA-10 `implements`** and ODCS `authoritativeDefinitions`.

Documentation pattern: [02. Documentation Standard](02.%20Documentation%20Standard.md)  
Parent hub: [Contracts](../00.%20README.md)

## Hierarchy

```text
Data Product
  ├── exposes ▶ Data Product Output Port ──governed by──▶ Data Contract ──contains──▶ Contract Field
  └── consumes ▶ Data Product Input Port
Port / Field ──implemented by──▶ Table / Column   (Technical Catalog)
Data Product / Contract / Field ──implements──▶ Registry Concept   (Control Plane)
```

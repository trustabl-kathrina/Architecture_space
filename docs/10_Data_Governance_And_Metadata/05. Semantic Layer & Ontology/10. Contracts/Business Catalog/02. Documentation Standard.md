# Business Catalog Documentation Standard

Every asset type in **`10. Contracts/Business Catalog/`** uses the same package layout as Technical Catalog.

## Per-asset package

```text
{AssetType}/
  00. README.md
  01. Characteristics.md
  contract.json
  example.json
```

## Characteristics table columns

Name · Public ID · Description · Kind · Asset Type Filter · Min · Max · System Managed · Read Only · Scope

Scope: `core` · `optional` · `regional` · `legacy`

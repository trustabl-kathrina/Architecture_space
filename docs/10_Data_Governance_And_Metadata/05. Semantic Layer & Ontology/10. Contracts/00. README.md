## Where the semantic layer lives

| Layer | Pack | Notes |
| --- | --- | --- |
| Collibra logical “semantic” model | **Business Catalog** | Data Model → Entity → Attribute |
| Enterprise semantic layer (canonical meaning) | **Semantic Control Plane** | Namespace · Concept · Mapping · Federation |
| Physical inventory | **Technical Catalog** | Never hosts concepts |
| Product packaging | **Data Products** | Binds to concepts via `implements` |

## End-to-end meaning path (summary)

```text
Business Catalog ──mapsTo──┐
Technical Catalog ─represents─┼──▶ Mapping Record ──▶ Concept (Control Plane)
Data Products ───implements──┘              ▲
Structural: Entity↔Table · Attribute↔Column · Port↔Table · Field↔Column
Federation: natco Concept ──▶ global Concept
```

# Technical Catalog Contracts

Collibra-style **asset type** documentation and JSON contracts for the Data Catalog **physical / technology** layer.

Researched from Collibra OOTB asset types and physical data layer guidance. Catalog SoR = Collibra / Dataplex. Control Plane consumes stable asset ids for Mapping Engine `represents`.

Documentation pattern: [02. Collibra Documentation Standard](02.%20Collibra%20Documentation%20Standard.md)  
Parent hub: [Contracts](../00.%20README.md)

## Canonical hierarchies

### Relational (physical data layer)

```text
System ──groups──▶ Database ──has──▶ Schema ──contains──▶ Table ──contains──▶ Column
                                              └─contains──▶ Database View ──contains──▶ Column
Foreign Key ──composed of / references──▶ Column
```

### File / object storage

```text
File Storage ──contains──▶ Directory ──contains──▶ File ──contains──▶ Field
```

Detail: [01. Hierarchy And Relations](01.%20Hierarchy%20And%20Relations.md) · [`hierarchy.relations.json`](hierarchy.relations.json)

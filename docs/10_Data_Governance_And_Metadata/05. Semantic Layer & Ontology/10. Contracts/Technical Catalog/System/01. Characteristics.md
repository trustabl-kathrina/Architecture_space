# System — Characteristics

Collibra **Characteristics** assignment for asset type **System**.  
Standard: [02. Collibra Documentation Standard](../02. Collibra Documentation Standard.md)

## Purpose

Define attributes and explicit relations that make up a System asset (Characteristics tab). Changes apply to admins until **Edit Layout** publishes the asset page.

## Asset type identity

| Field | Value |
| --- | --- |
| Asset type | System |
| Collibra path | `Technology Asset > System` |
| Parent type | Technology Asset |
| Assignment level | Enterprise core + optional as marked |
| Contract | [`contract.json`](contract.json) (`ctr-tech-type-system`) |

## Hierarchy role

groups Database (Technology Asset groups Technology Asset)

## Characteristics table

Columns match Collibra Characteristics UI. `—` in Max = unbounded. Filter `—` = attribute (not a relation).

| # | Name | Public ID | Description | Kind | Asset Type Filter | Min | Max | System Managed | Read Only | Scope |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | Description | `Description` | Verbose description of the system | Text | — | 1 | 1 | No | No | core |
| 2 | Scope | `Scope` | Business functions / applications automated by this system | Text | — | 1 | — | No | No | core |
| 3 | Location | `Location` | Where the system is deployed or operated | Text | — | 0 | — | No | No | optional |
| 4 | Last Sync Date | `LastSyncDate` | Date asset was synchronized with external system | Date | — | 0 | — | No | No | optional |
| 5 | Note | `Note` | A note | Text | — | 0 | — | No | No | optional |
| 6 | groups Database | `TechnologyAssetGroupsTechnologyAsset` | Links System to Database assets it groups | Explicit Relation | Database | 0 | — | No | No | core |
| 7 | impacted by Issue | `IssueImpactsAsset` | Links an issue and the asset it impacts | Explicit Relation | Issue | 0 | — | No | No | optional |

## Required / validation rules

| Rule | Detail |
| --- | --- |
| R1 | All `scope=core` characteristics with Min ≥ 1 are mandatory |
| R2 | Hierarchy relations must follow [01. Hierarchy And Relations](../01.%20Hierarchy%20And%20Relations.md) |
| R3 | Stable catalog `source_id` / full name for connectors and lineage stitching |
| R4 | Last Sync Date updated on successful scanner run when applicable |

## Assignment & layout

| Topic | Guidance |
| --- | --- |
| Global Assignment | Carry all `core` characteristics |
| NATCO Assignment | May add `optional` / `regional`; must not remove `core` |
| Edit Layout | Characteristics changes are admin-only until layout is published |

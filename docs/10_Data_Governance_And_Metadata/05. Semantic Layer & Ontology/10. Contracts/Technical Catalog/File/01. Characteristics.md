# File — Characteristics

Collibra **Characteristics** assignment for asset type **File**.  
Standard: [02. Collibra Documentation Standard](../02. Collibra Documentation Standard.md)

## Purpose

Define attributes and explicit relations that make up a File asset (Characteristics tab). Changes apply to admins until **Edit Layout** publishes the asset page.

## Asset type identity

| Field | Value |
| --- | --- |
| Asset type | File |
| Collibra path | `Technology Asset > File` |
| Parent type | Technology Asset |
| Assignment level | Enterprise core + optional as marked |
| Contract | [`contract.json`](contract.json) (`ctr-tech-type-file`) |

## Hierarchy role

is part of Directory or File Storage; contains Field

## Characteristics table

Columns match Collibra Characteristics UI. `—` in Max = unbounded. Filter `—` = attribute (not a relation).

| # | Name | Public ID | Description | Kind | Asset Type Filter | Min | Max | System Managed | Read Only | Scope |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | Description | `Description` | Verbose description of the file | Text | — | 1 | 1 | No | No | core |
| 2 | Description from source system | `DescriptionFromSourceSystem` | Source/scanner description | Text | — | 0 | 1 | No | No | optional |
| 3 | Location | `Location` | Full URI / path of the file | Text | — | 1 | — | No | No | core |
| 4 | File Type | `FileType` | e.g. CSV, PARQUET, JSON, XLSX | Text | — | 1 | 1 | No | No | core |
| 5 | Last Sync Date | `LastSyncDate` | Last sync from external system | Date | — | 0 | — | No | No | optional |
| 6 | Note | `Note` | A note | Text | — | 0 | — | No | No | optional |
| 7 | is part of Directory | `DirectoryContainsFile` | Parent directory | Explicit Relation | Directory | 0 | 1 | No | No | core |
| 8 | belongs to File Storage | `FileStorageContainsFile` | Parent storage when file is at bucket root | Explicit Relation | File Storage | 0 | 1 | No | No | optional |
| 9 | contains Field | `FileContainsField` | Fields / columns in the file schema | Explicit Relation | Field | 0 | — | No | No | core |
| 10 | impacted by Issue | `IssueImpactsAsset` | Links an issue and the asset it impacts | Explicit Relation | Issue | 0 | — | No | No | optional |

## Required / validation rules

| Rule | Detail |
| --- | --- |
| R1 | All `scope=core` characteristics with Min ≥ 1 are mandatory |
| R2 | Hierarchy relations must follow [01. Hierarchy And Relations](../01.%20Hierarchy%20And%20Relations.md) |
| R3 | Stable catalog `source_id` / full name for connectors and lineage stitching |
| R4 | Last Sync Date updated on successful scanner run when applicable |

## Assignment & layout

| Topic | Guidance |
| --- | --- |
| Global Assignment | Carry all `core` characteristics |
| NATCO Assignment | May add `optional` / `regional`; must not remove `core` |
| Edit Layout | Characteristics changes are admin-only until layout is published |

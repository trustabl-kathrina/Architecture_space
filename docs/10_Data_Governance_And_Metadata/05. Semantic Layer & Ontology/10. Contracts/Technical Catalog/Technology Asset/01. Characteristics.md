# Technology Asset — Characteristics

Collibra **Characteristics** assignment for asset type **Technology Asset**.  
Standard: [02. Collibra Documentation Standard](../02. Collibra Documentation Standard.md)

## Purpose

Define attributes and explicit relations that make up a Technology Asset asset (Characteristics tab). Changes apply to admins until **Edit Layout** publishes the asset page.

## Asset type identity

| Field | Value |
| --- | --- |
| Asset type | Technology Asset |
| Collibra path | `Technology Asset` |
| Parent type | — |
| Assignment level | Enterprise core + optional as marked |
| Contract | [`contract.json`](contract.json) (`ctr-tech-type-technology-asset`) |

## Hierarchy role

Parent of System, Database, File Storage, Directory, File

## Required / validation rules

| Rule | Detail |
| --- | --- |
| R1 | All `scope=core` characteristics with Min ≥ 1 are mandatory |
| R2 | Hierarchy relations must follow [01. Hierarchy And Relations](../01.%20Hierarchy%20And%20Relations.md) |
| R3 | Stable catalog `source_id` / full name for connectors and lineage stitching |
| R4 | Last Sync Date updated on successful scanner run when applicable |

## Assignment & layout

| Topic | Guidance |
| --- | --- |
| Global Assignment | Carry all `core` characteristics |
| NATCO Assignment | May add `optional` / `regional`; must not remove `core` |
| Edit Layout | Characteristics changes are admin-only until layout is published |

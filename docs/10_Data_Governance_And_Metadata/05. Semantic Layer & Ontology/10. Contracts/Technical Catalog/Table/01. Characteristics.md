# Table — Characteristics

Collibra **Characteristics** assignment for asset type **Table**.  
Standard: [02. Collibra Documentation Standard](../02.%20Collibra%20Documentation%20Standard.md)

## Purpose

Define attributes and explicit relations that make up a Table asset (Characteristics tab). Changes apply to admins until **Edit Layout** publishes the asset page.

## Asset type identity

| Field | Value |
| --- | --- |
| Asset type | Table |
| Parent type | Data Asset structure *(Operating Model dependent)* |
| Assignment level | Enterprise core + optional / regional as marked |
| Contract | [`contract.json`](contract.json) (`ctr-tech-type-table`) |

## Hierarchy role

```text
Database ──has──▶ Schema ──contains──▶ ▶ Table ──contains──▶ Column
```

| Name | Public ID | Target | Min | Max | Required |
| --- | --- | --- | --- | --- | --- |
| is part of Schema | `SchemaContainsTable` | Schema | 1 | 1 | Yes |

> Legacy public ids on some NATCO assignments: `SchemaContainsTable_C`, `ColumnsPartOfTable`. Prefer enterprise ids above; map legacy ids in connectors if needed.

## Required / validation rules

| Rule | Detail |
| --- | --- |
| R1 | Description and Description from source system mandatory |
| R2 | Table Type and Partitioned Flag mandatory |
| R3 | Exactly one parent Schema via **is part of Schema** |
| R4 | Columns registered via **contains Column** |
| R5 | Stable catalog `source_id` / qualified name for DA-09 mappings |
| R6 | Last Sync Date updated on successful scanner run |

## Assignment & layout

| Topic | Guidance |
| --- | --- |
| Global Assignment | Carry all `core` characteristics |
| NATCO Assignment | May add `optional` / `regional`; must not remove `core` |
| Edit Layout | Characteristics changes are admin-only until layout is published |
| Reorder | Keep hierarchy relations (#5–#6) near descriptive attributes |

## Domain types

Data Asset Domain (preferred). Subject-area domains when business ownership requires it.

## Instance checklist

1. Display name, Description, source description set  
2. Table Type and Partitioned Flag set  
3. Exactly one **is part of Schema**  
4. Columns linked via **contains Column**  
5. `example.json`-shaped instance validates against contract

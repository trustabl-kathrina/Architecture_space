# Table

Collibra **Asset Type** for a table, view, or similar relation object inside a schema.

## Asset type identity

| Field | Value |
| --- | --- |
| Display name | Table |
| Recommended public id | `Table` |
| Parent asset type | Data Asset / Technology structure *(Operating Model dependent)* |
| Product | Data Catalog / Data Governance |
| Hierarchy role | Intermediate (primary entity mapping grain) |
| Contract ID | `ctr-tech-type-table` |

## Purpose

Represent a **table** (or view) that belongs to one Schema and contains Columns. Primary catalog grain for Control Plane `represents` → entity concepts.

## Hierarchy position

```text
Database ──has──▶ Schema ──contains──▶ ▶ Table ──contains──▶ Column
```

| Direction | Relation | Target | Cardinality |
| --- | --- | --- | --- |
| Inbound / parent | is part of Schema | Schema | `1..1` |
| Outbound | contains Column | Column | `1..*` |

## Recommended domain types

| Domain type | Use |
| --- | --- |
| Data Asset Domain | Default home for Table instances |
| Subject-area domains | When tables are governed by business domain |

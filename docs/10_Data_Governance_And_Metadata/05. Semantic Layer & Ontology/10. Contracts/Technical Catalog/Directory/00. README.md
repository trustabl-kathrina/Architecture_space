# Directory

Collibra **Asset Type** — Folder / prefix in a file system or object store that contains files or nested directories.

## Asset type identity

| Field | Value |
| --- | --- |
| Display name | Directory |
| Collibra path | `Technology Asset > Storage Container > Directory` |
| Parent asset type | File Storage |
| Product | Data Catalog |
| Hierarchy role | intermediate |
| Contract ID | `ctr-tech-type-directory` |

## Purpose

Folder / prefix in a file system or object store that contains files or nested directories.

## Hierarchy position

belongs to File Storage or Directory; contains File / Directory

| Direction | Relation | Target | Cardinality |

| contains File | File | `0..*` |

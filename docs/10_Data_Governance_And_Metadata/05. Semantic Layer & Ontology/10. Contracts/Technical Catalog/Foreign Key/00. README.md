# Foreign Key

Collibra **Asset Type** — Models primary-key / foreign-key relationships between columns in relational databases.

## Purpose

Models primary-key / foreign-key relationships between columns in relational databases.

## Hierarchy position

Constraint asset linking Column (FK) to Column (PK/referenced)

| Direction | Relation | Target | Cardinality |
| --- | --- | --- | --- |
| is part of Table | Table | `1..1` |
| is composed of Column | Column | `1..*` |
| references Column | Column | `1..*` |

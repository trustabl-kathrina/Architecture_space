# Semantic Control Plane Contracts

**Enterprise meaning SoR** — namespaces, concepts, mapping records, and federation edges.

This pack is **not** Collibra inventory. Collibra’s Guided Stewardship “semantic layer” (Data Model / Entity / Attribute) lives in [Business Catalog](../Business%20Catalog/).

| Type | DA | Role |
| --- | --- | --- |
| [Namespace](Namespace/) | DA-02 | Scopes concept URIs (`global`, `natco-*`, `import-*`) |
| [Concept](Concept/) | DA-04 | Unit of meaning (`entity`, `shared_property`, `metric`, …) |
| [Mapping Record](Mapping%20Record/) | DA-08/09/10 | Crosswalk catalog/product → Concept |
| [Federation Edge](Federation%20Edge/) | DA-11 | NATCO/import Concept → `global` Concept |

Documentation: [02. Documentation Standard](02.%20Documentation%20Standard.md) · Parent: [Contracts](../00.%20README.md)

## How catalogs connect here

```text
Business Catalog  ──mapsTo (DA-08)──────┐
Technical Catalog ──represents (DA-09)──┼──▶ Mapping Record ──targets──▶ Concept
Data Products     ──implements (DA-10)──┘         │
                                                  │ belongs to
                                                  ▼
                                              Namespace
NATCO Concept ──Federation Edge──▶ global Concept
```

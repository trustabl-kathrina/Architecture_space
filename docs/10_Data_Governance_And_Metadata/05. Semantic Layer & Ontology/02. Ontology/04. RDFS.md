# RDFS

## Purpose

Specify **RDFS** constructs used alongside OWL for lightweight schema semantics.

## v1 usage

| Construct | Use |
| --- | --- |
| `rdfs:label` / `rdfs:comment` | Human labels and short descriptions |
| `rdfs:subClassOf` / `rdfs:subPropertyOf` | Hierarchies |
| `rdfs:domain` / `rdfs:range` | Property typing |
| `rdfs:seeAlso` | Links to Business Catalog / Modeling docs |

Prefer RDFS + simple OWL over heavy axiomatization in v1.

# JSON-LD

## Purpose

Specify **JSON-LD** as an **optional** linked-data export format. Primary interchange for published semantics is **Apache Ossie** JSON/YAML—see [Apache Ossie](08.%20Apache%20Ossie.md).

## v1 usage

- Prefer Ossie JSON/YAML for API and file exchange
- JSON-LD may be emitted where RDF tooling requires compacted graphs
- Crosswalk records remain MCP metadata objects; export projections may use JSON-LD when needed

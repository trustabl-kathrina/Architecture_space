# SKOS

## Purpose

Specify how **SKOS** may complement glossary taxonomies as an **optional** export. Primary publication of terms and metrics for interchange is **[Apache Ossie](08.%20Apache%20Ossie.md)**.

## v1 usage

| Construct | Use |
| --- | --- |
| `skos:Concept` | Glossary terms and controlled values |
| `skos:prefLabel` / `skos:altLabel` | Preferred name and synonyms |
| `skos:definition` | Definition text or link annotation |
| `skos:broader` / `skos:narrower` | Taxonomy |
| `skos:related` | Associative links |
| `skos:ConceptScheme` | Domain or enterprise scheme containers |

## Mapping rule

Each approved Business Catalog glossary term that is in scope for the pilot **must** have a SKOS concept URI via [Business Mapping](../05.%20Enterprise%20Mapping/01.%20Business%20Mapping.md). Entity types that are also glossary terms may have both a SKOS concept and an OWL class, linked explicitly.

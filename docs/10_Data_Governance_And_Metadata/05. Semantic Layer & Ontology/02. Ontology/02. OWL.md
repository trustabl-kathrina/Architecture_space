# OWL

## Purpose

Specify how **OWL** may be used as an **optional** formalization or export path for the Semantic Control Plane. Primary interchange is **[Apache Ossie](08.%20Apache%20Ossie.md)**—not OWL as SoR.

## v1 usage

| Feature | Use |
| --- | --- |
| `owl:Class` | Canonical entities / concept kinds `entity` |
| `owl:ObjectProperty` / `owl:DatatypeProperty` | Semantic relationships and attributes |
| `rdfs:domain` / `rdfs:range` | Property endpoints |
| `rdfs:subClassOf` | Entity specialization |
| Annotation properties | Labels, definitions, status, replaced_by |

## Explicitly deferred

- Complex class expressions as primary modeling style
- Enterprise-wide automated consistency proving as a launch gate
- Heavy use of `owl:sameAs` for operational master data (see entity resolution later)

# RDF

## Purpose

Establish **RDF** as the underlying graph model for ontology publication and interchange.

## v1 usage

- All ontology artifacts are expressible as RDF triples
- Preferred file serializations: Turtle (`.ttl`) for authoring/review; JSON-LD for APIs
- Every published concept has a dereferenceable IRI policy (API and/or content negotiation — implementation detail)

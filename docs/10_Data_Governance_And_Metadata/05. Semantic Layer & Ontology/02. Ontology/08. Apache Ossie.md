# Apache Ossie

## Purpose

Establish **[Apache Ossie](https://github.com/apache/ossie)** (incubating; formerly OSI) as the enterprise **semantic package exchange** standard—not a metadata repository.

**Canonical package contract (DA-14):** [Ossie Package Contract](../01.%20Foundation/19.%20Ossie%20Package%20Contract.md).

## Decision (locked)

| Concern | Decision |
| --- | --- |
| Enterprise meaning SoR | **Semantic Control Plane** |
| Data products / UI | **Entropy Marketplace** |
| Interchange | **Apache OSSIE** import / export / version packages only |

OSSIE **does not** store enterprise metadata. It packages and exchanges semantic definitions with NATCOs, partners, tools, and platforms.

## What Ossie provides

| Capability | Use |
| --- | --- |
| Core spec / schema | Shape + release validation gate |
| YAML / JSON packages | Portable semantic models |
| Converters | Interop with BI / dbt / other formats |
| Validation tooling | CI / lifecycle checks |

## Package content

- Concepts / namespace definitions  
- Ontology / taxonomy  
- Relationships  
- Business glossary extracts (derived)  
- Version metadata  

## Publication contract

1. Governance Engine approves Registry / Ontology slice  
2. Build emits Ossie package (`global` and/or `natco-*`)  
3. Validate against Ossie schema  
4. Version, tag, publish to object storage / exchange endpoint  
5. External parties import; control plane may import partner packages into staging → review  

## Relationship to other standards

| Standard | Role |
| --- | --- |
| Ossie | **Primary** interchange |
| SKOS / OWL / RDF / SHACL / JSON-LD | Optional paths |
| BI native models | **Consume** via converters or certified URIs |

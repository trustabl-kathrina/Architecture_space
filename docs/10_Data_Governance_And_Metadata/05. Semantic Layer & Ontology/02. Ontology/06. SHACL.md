# SHACL

## Purpose

Specify how **SHACL** may be used as an **optional** constraint export. Primary release validation is against the **Ossie schema**—see [Apache Ossie](08.%20Apache%20Ossie.md) and [Ontology Lifecycle](../05.%20Enterprise%20Mapping/04.%20Ontology%20Lifecycle.md).

## v1 usage

| Use case | Shape purpose |
| --- | --- |
| Concept completeness | Required labels, definition_ref, owner, status |
| Mapping integrity | Crosswalk records must reference `approved` target URIs |
| Product binding | Product contract must list ≥1 approved concept URI |
| Property cardinality | Optional business rules on relationship endpoints |

## API hook

Primary Semantic API `validate` runs against the **Ossie schema**. SHACL validation remains optional for RDF export paths only. See [APIs](../07.%20Engineering/01.%20APIs.md).

# Integrations

## Purpose

Inbound and outbound integrations for the Semantic Control Plane.

## Inbound (connectors)

| System | Direction | Purpose |
| --- | --- | --- |
| Collibra | In | Business (± technical) metadata |
| Dataplex | In | Technical metadata |
| TM Forum SID | In | Bootstrap `global/` |
| REST / file / events | In | Generic / incremental sync |
| Apache OSSIE | In | Import partner / NATCO packages (staging → review) |

## Outbound

| System | Direction | Purpose |
| --- | --- | --- |
| Entropy Marketplace | Out (API) | Enrichment, reverse lookup, binding validation |
| Apache OSSIE | Out | Publish packages |
| AI / BI / Apps | Out (API) | Runtime semantic access |
| MCP Server | Out | Agent tools |

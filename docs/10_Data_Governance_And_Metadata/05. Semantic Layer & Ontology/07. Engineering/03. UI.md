# UI

## Purpose

Record the **headless** decision: the Semantic Control Plane has **no first-party UI**.

## Decision

| Surface | Owner |
| --- | --- |
| Product discovery, lifecycle, bindings UX | **Entropy Marketplace** |
| Semantics browse / diagram in product context | **Entropy Semantics** (Marketplace) |
| Control plane | **APIs only** |

Admin/break-glass tooling may exist for platform operators; it is not the enterprise user experience.

# Events

## Purpose

Change events emitted by the Semantic Control Plane for Marketplace, catalogs, search, and agents.

## Event catalog (v1)

| Event | When |
| --- | --- |
| `concept.approved` / `concept.deprecated` | Governance state change |
| `namespace.updated` | Namespace metadata change |
| `mapping.created` / `mapping.updated` | Mapping Engine |
| `federation.edge.changed` | Federation Engine |
| `ossie.released` | Package published |
| `product.binding.changed` | Marketplace binding sync |

Transport: Kafka / PubSub (foundation). Consumers must be idempotent.

# Security

## Purpose

Security and access control for the Semantic Control Plane.

## Controls

| Control | Approach |
| --- | --- |
| Authentication | Enterprise IAM |
| Authorization | Role + namespace scope (see [APIs](01.%20APIs.md)) |
| NATCO isolation | Write confined to owned `natco-*` unless Global role |
| Audit | All mutating API calls and governance decisions |
| Secrets | Connector credentials in enterprise secret store |
| Packages | Signed / checksummed Ossie artifacts on release |

# Graph Traversal

## Purpose

Define how consumers walk the Knowledge Graph via the **Graph API**.

## Patterns

| Pattern | Use |
| --- | --- |
| Neighbors | “What maps to Customer?” |
| Bounded expand | Depth-N context for AI prompts |
| Path | Asset → concept → product |
| Impact | Concept change → affected products / assets |

## Rules

- Default: `status=approved` edges only  
- Cap depth (e.g. 3) unless privileged  
- Prefer federation to `global/` when resolving cross-NATCO context

# Relationships

## Purpose

Typed edges in the Knowledge Graph (aligned with the Mapping and Federation engines).

## Edge catalog (v1)

| Predicate | From → To | Engine |
| --- | --- | --- |
| `mapsTo` | BusinessTerm → Concept | Mapping |
| `represents` | TechnicalAsset → Concept | Mapping |
| `implements` / `authoritativeDefinition` | DataProduct → Concept | Mapping |
| `sameAs` / `specializes` / `extends` / `implements` | Concept → Concept | Federation |
| `owns` / `contains` / `belongsTo` | Concept → Concept | Ontology |
| `governedBy` | Concept / Product → Policy | Governance |
| `measures` | Metric → Concept | Ontology |

Shared attributes: `confidence`, `owner`, `status`, `effective_from`, `version`.

# Nodes

## Purpose

Define node classes in the Enterprise Knowledge Graph.

## Node classes

| Class | Source of truth | Examples |
| --- | --- | --- |
| **Concept** | Semantic Registry | Customer, Account, SIM, Product |
| **BusinessTerm** | Catalog (mapped) | Collibra term ID |
| **TechnicalAsset** | Catalog (mapped) | Table, column, pipeline |
| **DataProduct** | Entropy Marketplace | ODPS product / port |
| **Metric / KPI** | Registry / Modeling | MRR, Churn |
| **Policy** | Governance Engine | Classification, retention |
| **Namespace** | Namespace Registry | `global`, `natco-de` |

## Required properties

`id` / URI, `label`, `namespace`, `status`, `owner`, `version`, `source_system` (when mapped).

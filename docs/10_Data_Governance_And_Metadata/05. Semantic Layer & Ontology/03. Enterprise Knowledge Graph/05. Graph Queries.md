# Graph Queries

## Purpose

Logical query shapes exposed by the Graph API (implementation may use Cypher or equivalent).

## Example intents

| Intent | Logical query |
| --- | --- |
| Products for a concept | `(DataProduct)-[:implements]->(Concept {uri})` |
| Assets for a concept | `(TechnicalAsset)-[:represents]->(Concept)` |
| NATCO→global | `(Concept {ns:natco})-[:sameAs|specializes]->(Concept {ns:global})` |
| Impact | Expand from Concept along `implements` / `represents` reverse |

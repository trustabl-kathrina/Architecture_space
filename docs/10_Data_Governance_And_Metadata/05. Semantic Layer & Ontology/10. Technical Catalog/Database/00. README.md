# Database

Collibra **Asset Type** for a physical or logical database (technology asset specializing structural containment of schemas).

## Asset type identity

| Field | Value |
| --- | --- |
| Display name | Database |
| Recommended public id | `Database` |
| Parent asset type | Technology Asset |
| Product | Data Catalog / Data Governance |
| Hierarchy role | Root |
| Contract ID | `ctr-tech-type-database` |

## Purpose

Represent the **database** system that owns one or more schemas. Used by scanners and stewards as the top of the technical containment chain. Not a primary Mapping Engine `represents` target.

## Hierarchy position

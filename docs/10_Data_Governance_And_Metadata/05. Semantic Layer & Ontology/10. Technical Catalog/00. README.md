# Technical Catalog Asset Templates

Collibra-style **asset type** documentation and JSON contracts for the technical catalog hierarchy.

Catalog SoR = Collibra / Dataplex. Control Plane consumes stable asset ids for Mapping Engine `represents`. Every asset is documented the **same way** — see [02. Collibra Documentation Standard](02.%20Collibra%20Documentation%20Standard.md).

## Canonical hierarchy

```text
Database ──has──▶ Schema ──contains──▶ Table ──contains──▶ Column
```

| From | Relation | To | Inverse |
| --- | --- | --- | --- |
| Database | `has` | Schema | Schema `belongs to` Database |
| Schema | `contains` | Table | Table `is part of` Schema |
| Table | `contains` | Column | Column `is part of` Table |

Detail: [01. Hierarchy And Relations](01.%20Hierarchy%20And%20Relations.md) · [`hierarchy.relations.json`](hierarchy.relations.json)

## Characteristics table columns (Collibra UI)

Name · Public ID · Description · Kind · Asset Type Filter · Min · Max · System Managed · Read Only · Scope

Scope: `core` · `optional` · `regional` · `legacy`

## SoR & Control Plane boundary

| Concern | System |
| --- | --- |
| Asset inventory + characteristics | Collibra / Dataplex (**SoR**) |
| Hierarchy relations | Catalog (**SoR**) |
| Concept meaning (`represents`) | Semantic Control Plane Mapping Engine |
| Typical mapping grain | **Table** → entity · **Column** → property |

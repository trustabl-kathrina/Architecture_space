# Column

Collibra **Asset Type** for a column (field) that is part of a table.

## Asset type identity

| Field | Value |
| --- | --- |
| Display name | Column |
| Recommended public id | `Column` |
| Parent asset type | Data Asset structure *(Operating Model dependent)* |
| Product | Data Catalog / Data Governance |
| Hierarchy role | Leaf (primary property mapping grain) |
| Contract ID | `ctr-tech-type-column` |

## Purpose

Represent a **column** belonging to exactly one Table. Carries technical datatype, nullability, and key metadata. Primary catalog grain for Control Plane `represents` → property / identifier concepts.

## Hierarchy position

```text
Database ──has──▶ Schema ──contains──▶ Table ──contains──▶ ▶ Column
```

| Direction | Relation | Target | Cardinality |
| --- | --- | --- | --- |
| Inbound / parent | is part of Table | Table | `1..1` |

## Recommended domain types

| Domain type | Use |
| --- | --- |
| Data Asset Domain | Default home for Column instances |
| Same domain as parent Table | Preferred for traversal / permissions |

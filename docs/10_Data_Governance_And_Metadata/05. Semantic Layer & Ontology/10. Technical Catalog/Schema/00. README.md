# Schema

Collibra **Asset Type** for a database schema / namespace that contains tables.

## Asset type identity

| Field | Value |
| --- | --- |
| Display name | Schema |
| Recommended public id | `Schema` |
| Parent asset type | Technology Asset *(or Catalog Asset — keep consistent with Operating Model)* |
| Product | Data Catalog / Data Governance |
| Hierarchy role | Intermediate |
| Contract ID | `ctr-tech-type-schema` |

## Purpose

Represent the **schema** (namespace) between a Database and its Tables. Every Schema must belong to exactly one Database. Structural context only for Mapping Engine.

## Hierarchy position

```text
Database ──has──▶ ▶ Schema ──contains──▶ Table ──contains──▶ Column
```

| Direction | Relation | Target | Cardinality |
| --- | --- | --- | --- |
| Inbound / parent | belongs to Database | Database | `1..1` |
| Outbound | contains Table | Table | `0..*` |

## Recommended domain types

| Domain type | Use |
| --- | --- |
| Technology Asset Domain | Default home for Schema instances |
| Same domain as parent Database | Preferred for traversal / permissions |

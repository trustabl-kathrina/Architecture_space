# Non Functional Requirements

## Purpose

Quality attributes for the Semantic Control Plane.

## Requirements

| ID | Concern | Target (pilot → scale) |
| --- | --- | --- |
| NFR-1 | Lookup latency | Sub-second interactive p95 |
| NFR-2 | Availability | Align with MCP control-plane SLO |
| NFR-3 | Security | IAM; domain authZ; audit all writes |
| NFR-4 | Tenancy / NATCO isolation | Namespace-scoped write rights |
| NFR-5 | Auditability | Immutable history of concept and mapping changes |
| NFR-6 | Extensibility | New connector without redesigning core |
| NFR-7 | Observability | Metrics, logs, traces on APIs and connectors |
| NFR-8 | Package integrity | Ossie schema validation on release |

## Foundation services

PostgreSQL, Neo4j, pgVector, Redis, Kafka, object storage, IAM, monitoring — see [Architecture](05.%20Architecture.md).

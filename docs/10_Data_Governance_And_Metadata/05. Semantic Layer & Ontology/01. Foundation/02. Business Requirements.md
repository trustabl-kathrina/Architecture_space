# Business Requirements

## Purpose

Business needs for the Enterprise Semantic Control Plane.

## Requirements

| ID | Requirement | Priority |
| --- | --- | --- |
| BR-1 | One enterprise vocabulary aligned to TM Forum where applicable | Must |
| BR-2 | Cross-NATCO comparable meaning without forcing one catalog vendor | Must |
| BR-3 | Marketplace products discoverable and enrichable by enterprise meaning | Must |
| BR-4 | Federated ownership: NATCOs keep local catalogs and local extensions | Must |
| BR-5 | Open interchange with partners via Apache OSSIE packages | Should |
| BR-6 | AI agents retrieve certified semantic context safely | Should |
| BR-7 | Domain experts work primarily via Marketplace UI (no separate control-plane UI) | Must |

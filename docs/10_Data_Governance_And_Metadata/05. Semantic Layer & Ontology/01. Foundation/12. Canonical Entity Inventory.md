# Canonical Entity Inventory — Pilot (DA-05)

## Purpose

Author the **pilot canonical entity inventory** as Semantic Registry **draft** records in `global`, based on [TM Forum SID Pilot Slice (DA-03)](10.%20TM%20Forum%20SID%20Pilot%20Slice.md) Tier A (+ navigation groups). Data Architecture deliverable for roadmap task **DA-05**.

Schema: [Semantic Registry Schema (DA-04)](11.%20Semantic%20Registry%20Schema.md).  
Narrative: [Canonical Entities](../04.%20Enterprise%20Semantics/01.%20Canonical%20Entities.md).

## Decision (locked)

| # | Decision |
| --- | --- |
| 1 | Pilot inventory = **10 entities** (Tier A) + **4 groups** (Tier C) in namespace **`global`**. |
| 2 | All records start as **`status: draft`** until Governance promotes to `review` / `approved`. |
| 3 | URI base placeholder: `https://semantics.{enterprise}/ns/global/{concept_id}` — replace `{enterprise}` at implementation. |
| 4 | `sid_version` annotation set to **`R20.0`** as reference baseline; adjust when licensed package version is confirmed. |
| 5 | Tier B shared properties are **listed** here for binding intent; full property records can follow in the same sprint (optional stretch). |

# Azure Logic Apps Learning Guide

Structured learning path for architects and engineers implementing **serverless integration and operational orchestration** with Azure Logic Apps — connectors, approvals, alerts, and ADF glue.

## Prerequisites

- Azure subscription with Logic Apps access
- Familiarity with [Logic Apps Architecture](../02.03.02.04.02_Logic_Apps_Architecture.md)
- Basic IAM and JSON workflow concepts
- Optional: Event Grid, Service Bus, or Teams integration experience

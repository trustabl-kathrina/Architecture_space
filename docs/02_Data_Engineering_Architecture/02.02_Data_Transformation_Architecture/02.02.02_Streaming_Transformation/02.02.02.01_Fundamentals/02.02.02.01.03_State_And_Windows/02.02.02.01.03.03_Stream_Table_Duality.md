# Stream-Table Duality

## Concept

A **changelog stream** can rebuild a **table**; a **table** can emit a **changelog stream** (CDC). Unified engines (Flink SQL, Materialize) exploit this duality.

## Implications for transforms

| Direction | Pattern |
| --- | --- |
| Stream to Table | Aggregating sink, MERGE into lake |
| Table to Stream | CDC source, binlog capture |
| Stream join Stream | Join stream with table (temporal join) |

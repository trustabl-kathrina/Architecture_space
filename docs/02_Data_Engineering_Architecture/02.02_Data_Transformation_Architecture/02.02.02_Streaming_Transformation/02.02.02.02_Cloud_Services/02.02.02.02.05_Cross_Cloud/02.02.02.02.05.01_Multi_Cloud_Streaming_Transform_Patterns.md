# Multi-Cloud Streaming Transform Patterns

## Patterns

| Pattern | Description |
| --- | --- |
| **Portable Beam** | Same pipeline on Dataflow, Flink, Spark runner |
| **Kafka as bus** | MSK/Confluent Cloud neutral transport |
| **Dual write** | Transform in primary cloud, replicate gold to DR |
| **Federated query** | Trino over multi-cloud silver tables |

## Governance

- Unified schema registry (Confluent/Glue).
- Cross-cloud IAM via workload identity federation.
- Single observability plane (OpenTelemetry).

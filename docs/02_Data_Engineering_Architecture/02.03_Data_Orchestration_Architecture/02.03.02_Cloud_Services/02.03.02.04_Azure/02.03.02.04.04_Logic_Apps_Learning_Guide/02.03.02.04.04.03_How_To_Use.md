# 3. How to Use Azure Logic Apps

## Setup prerequisites

1. Choose **Consumption** vs **Standard** plan (see [Overview](02.03.02.04.04.01_Overview.md)).
2. Resource group and region aligned with ADF/Event Grid.
3. **Managed identity** for Azure resource calls.
4. Naming: `la-{domain}-{purpose}-{env}`.

## Create Logic App (Consumption) — Azure CLI

```bash
az logic workflow create \
  --resource-group rg-analytics-prod \
  --location westeurope \
  --name la-adf-failure-alert-prod \
  --definition @workflow.json
```

## Sample workflow — ADF pipeline failure alert

**`workflow.json` (simplified):**

```json
{
  "definition": {
    "$schema": "https://schema.management.azure.com/providers/Microsoft.Logic/schemas/2016-06-01/workflowdefinition.json#",
    "triggers": {
      "When_pipeline_fails": {
        "type": "ApiConnectionWebhook",
        "inputs": {
          "host": { "connection": { "name": "@parameters('$connections')['eventgrid']['connectionId']" } },
          "body": {
            "properties": {
              "topic": "/subscriptions/{sub}/resourceGroups/rg-analytics-prod/providers/Microsoft.DataFactory/factories/adf-analytics-prod",
              "filter": {
                "includedEventTypes": ["Microsoft.DataFactory.PipeLineRun.Failed"]
              }
            }
          }
        }
      }
    },
    "actions": {
      "Post_to_Teams": {
        "type": "ApiConnection",
        "runAfter": {},
        "inputs": {
          "host": { "connection": { "name": "@parameters('$connections')['teams']['connectionId']" } },
          "method": "post",
          "path": "/v1.0/teams/{teamId}/channels/{channelId}/messages",
          "body": {
            "body": {
              "content": "Pipeline failed: @{triggerBody()?['data']?['pipelineName']}"
            }
          }
        }
      }
    }
  }
}
```

## Invoke ADF pipeline from Logic App

**HTTP action** to Data Factory REST API:

```
POST https://management.azure.com/subscriptions/{sub}/resourceGroups/{rg}/providers/Microsoft.DataFactory/factories/{factory}/pipelines/{pipeline}/createRun?api-version=2018-06-01
```

Authenticate with **managed identity** — assign `Data Factory Contributor` or custom role with `Microsoft.DataFactory/factories/pipelines/createRun/action`.

## HTTP Request trigger (webhook ingress)

```json
"triggers": {
  "manual": {
    "type": "Request",
    "kind": "Http",
    "inputs": { "schema": { "type": "object", "properties": { "filePath": { "type": "string" } } } }
  }
}
```

Use for external systems to kick off lightweight orchestration before ADF.

## Retry and concurrency (action settings)

```json
"Post_to_Teams": {
  "type": "ApiConnection",
  "runAfter": {},
  "retryPolicy": {
    "type": "exponential",
    "count": 4,
    "interval": "PT10S",
    "minimumInterval": "PT5S",
    "maximumInterval": "PT1H"
  },
  "inputs": { ... }
}
```

## Bicep deploy (Standard plan sketch)

```bicep
resource logicApp 'Microsoft.Web/sites@2022-03-01' = {
  name: 'la-ops-prod'
  location: location
  kind: 'functionapp,workflowapp'
  identity: { type: 'SystemAssigned' }
  properties: { serverFarmId: appServicePlan.id }
}
```

## Observability

- **Logic app run history** — per-action inputs/outputs (redact PII).
- **Log Analytics** — diagnostic setting `WorkflowRuntime`.
- **Application Insights** (Standard) for latency and failure rates.
- **Alerts** — Runs Failed metric > threshold.

## Operational checklist

- [ ] Managed identity for Azure calls
- [ ] Key Vault for OAuth connector secrets
- [ ] Retry on transient connector failures
- [ ] Separate Consumption apps per domain for cost attribution
- [ ] Standard plan for VNet/private API requirements
- [ ] Workflow JSON in Git — not designer-only

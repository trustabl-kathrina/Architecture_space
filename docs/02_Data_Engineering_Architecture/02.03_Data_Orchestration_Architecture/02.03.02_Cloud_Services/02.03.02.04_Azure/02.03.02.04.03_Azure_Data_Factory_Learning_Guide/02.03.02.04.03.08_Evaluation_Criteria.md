# 8. Azure Data Factory Evaluation Criteria

Compare **ADF/Fabric** vs **Logic Apps**, **MWAA**, and **Cloud Composer**.

**Rating scale:** 1 (weak) — 5 (excellent)

## Scorecard

| Criterion | Weight | ADF | Logic Apps | MWAA | Composer |
| --- | ---: | ---: | ---: | ---: | ---: |
| **Azure native data integration** | High | 5 | 3 | 2 | 1 |
| **Large-scale ETL / copy** | High | 5 | 1 | 4 | 4 |
| **Serverless / idle cost** | High | 5 | 5 | 2 | 2 |
| **Portable orchestration code** | Medium | 2 | 1 | 5 | 5 |
| **Visual / low-code authoring** | Medium | 5 | 5 | 2 | 2 |
| **Hybrid on-prem** | High | 5 | 3 | 3 | 3 |
| **Purview / lineage** | Medium | 5 | 2 | 3 | 4 |
| **SaaS connectors** | Medium | 3 | 5 | 3 | 3 |
| **Complex DAG backfill** | Medium | 4 | 2 | 5 | 5 |
| **Multi-cloud portability** | Medium | 1 | 1 | 3 | 2 |

## Decision matrix

| If priority is… | Choose |
| --- | --- |
| Azure lakehouse batch ELT | **ADF / Fabric** |
| Teams alert + approval glue | **Logic Apps** |
| Portable Airflow DAGs | **MWAA / Composer / AKS Airflow** |
| Microsoft + SAP B2B | **Logic Apps** + Integration Account |
| Hybrid Azure platform | **ADF + Logic Apps** |

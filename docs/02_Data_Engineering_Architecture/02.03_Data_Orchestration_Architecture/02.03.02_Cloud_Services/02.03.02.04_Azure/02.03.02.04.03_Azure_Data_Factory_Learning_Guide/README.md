# Azure Data Factory Learning Guide

Structured learning path for architects and engineers implementing **cloud ETL and pipeline orchestration** with Azure Data Factory (ADF) and Microsoft Fabric Data Factory patterns.

## Prerequisites

- Azure subscription with Data Factory access
- Familiarity with [Azure Data Factory Architecture](../02.03.02.04.01_Azure_Data_Factory_Architecture.md)
- Basic understanding of pipelines, triggers, and linked services
- Optional: Synapse, Databricks, or Purview experience

# 6. AWS Glue Workflows Costing

> **Source of truth:** [AWS Glue pricing](https://aws.amazon.com/glue/pricing/) — verify rates before budgeting. **Glue Workflows have no separate orchestration charge**; you pay for crawlers and jobs.

## Cost components

| Component | Billing |
| --- | --- |
| **ETL Spark jobs** | DPU-second (1-minute minimum); Standard vs **Flex** pricing |
| **Crawlers** | DPU-second (10-minute minimum) |
| **Python shell jobs** | Fractional DPU (0.0625 DPU default) |
| **Data Catalog** | First 1M objects + 1M accesses/month free; then per-object/access fees |
| **Workflow engine** | **$0** — orchestration included in Glue |
| **Downstream** | Athena queries, S3 storage — not included |

**Key FinOps insight:** Workflow design affects **order and parallelism** of DPU consumption, not orchestrator idle cost (unlike MWAA).

## DPU pricing (indicative — us-east-1)

| Resource | Typical rate |
| --- | --- |
| Spark job (Standard) | **~$0.44 / DPU-hour** |
| Spark job (Flex) | **~35% lower** than Standard (verify region) |
| Crawler | **~$0.44 / DPU-hour** |
| G.1X worker | 1 DPU per worker |
| G.2X worker | 2 DPUs per worker |

## Scenario cost models

### Scenario A — Nightly medallion (moderate)

| Assumption | Value |
| --- | --- |
| Crawler | 2 DPUs × 15 min = 0.5 DPU-hr → **~$0.22** |
| Bronze job | 6 DPUs × 20 min = 2 DPU-hr → **~$0.88** |
| Silver job | 10 DPUs × 30 min = 5 DPU-hr → **~$2.20** |
| **Nightly total** | **~$3.30** × 30 ≈ **~$99/month** |

### Scenario B — Hourly incremental (bookmark)

| Assumption | Value |
| --- | --- |
| Skip crawler (catalog current) | $0 |
| Incremental job | 4 DPUs × 5 min × 24 × 30 ≈ 96 DPU-hr → **~$42/month** |

### Scenario C — Backfill burst (Flex)

| Assumption | Value |
| --- | --- |
| 30-day parallel backfill | 20 DPUs × 2 hr × 30 runs |
| Use **Flex** | ~35% savings vs Standard |
| **Est.** | **~$170–260** one-time (order of magnitude) |

### Scenario D — Glue Workflows vs MWAA (Glue-only pipeline)

| | Glue Workflows | MWAA (mw1.small) |
| --- | --- | --- |
| Orchestration fee | **$0** | **~$353/month** baseline |
| Compute | DPU when jobs run | DPU/EMR + worker idle |
| **Winner for pure Glue** | **Glue Workflows** | Platform with mixed services |

### Scenario E — Glue Workflows vs Step Functions (single job chain)

| | 3 Glue jobs nightly | Step Functions + Glue |
| --- | --- | --- |
| Orchestration | $0 | ~$0.01–0.05 transitions |
| Compute | Same DPU | Same DPU |
| **Difference** | Negligible orchestration cost either way | SF adds cross-service steps easily |

## Cost optimization checklist

1. **Flex execution class** for non-T0 jobs.
2. **Right-size workers** — start with G.1X; benchmark before G.2X.
3. **Job bookmarks** — avoid full re-reads.
4. **Crawler frequency** — don't crawl more than metadata SLA requires.
5. **Consolidate jobs** — fewer Spark startups = less overhead.
6. **MaxConcurrentRuns** — prevent overlapping backfills.
7. **Enable job metrics** — identify straggler stages in Cost Explorer tags.

# 7. How to Configure MWAA for Production

## Configuration matrix

| Goal | Environment settings | DAG settings | Monitoring |
| --- | --- | --- | --- |
| **T0 SLA (06:00 finish)** | mw1.medium+; min workers 2; max 20 | `max_active_runs=1`; pools; timeouts | SLA sensor; PagerDuty |
| **Cost-efficient dev** | mw1.small; min 1; max 3 | `catchup=False` | Budget alerts |
| **High parallelism** | mw1.large; high max workers | Pools per Glue/Redshift | Queue depth alarm |
| **Private / regulated** | PRIVATE_ONLY webserver; VPC endpoints | Secrets Manager connections | CloudTrail + log retention |
| **Fast DAG iteration** | Staging mirrors prod Airflow version | CI import test | Parse error alarm |

## Recipe 1 — T0 finance close DAG

**Target:** Complete ledger pipeline by 06:00 UTC.

```python
default_args = {
    "retries": 3,
    "retry_delay": timedelta(minutes=5),
    "execution_timeout": timedelta(hours=2),
    "pool": "redshift_finance",
}
# schedule="0 1 * * *", max_active_runs=1, catchup=False
```

Environment: `mw1.medium`, `minWorkers=3`, `maxWorkers=16`, `schedulers=2`.

## Recipe 2 — High-volume hourly loads

Environment: `mw1.large`, `minWorkers=4`, `maxWorkers=25`.

```python
with DAG(..., schedule="@hourly", max_active_runs=3) as dag:
    # Use dynamic task mapping sparingly; prefer Glue for bulk
```

## Recipe 3 — Private webserver + SSO

- `webserver-access-mode: PRIVATE_ONLY`
- Access via corporate VPN or AWS Client VPN.
- Optional: IAM Identity Center integration for Airflow UI.

## Recipe 4 — Secrets and connections

MWAA configuration options:

```json
{
  "secrets.backend": "airflow.providers.amazon.aws.secrets.secrets_manager.SecretsManagerBackend",
  "secrets.backend_kwargs": "{\"connections_prefix\": \"airflow/connections\"}"
}
```

Rotate secrets in Secrets Manager; avoid hardcoded credentials in DAGs.

## Recipe 5 — EventBridge trigger to MWAA

Lambda assumes execution role, obtains CLI token, POSTs to Airflow REST API with OIDC/IAM auth pattern per [AWS guidance](https://docs.aws.amazon.com/mwaa/latest/userguide/call-mwaa-apis.html).

## Monitoring thresholds

| Metric | Warning | Critical |
| --- | --- | --- |
| `QueuedTasks` sustained | &gt; 50 for 15 min | &gt; 200 for 30 min |
| `SchedulerHeartbeat` missing | 1 interval | 3 intervals |
| DAG parse errors | Any new error | Blocks production deploy |
| Worker CPU | &gt; 80% sustained | Autoscale max hit |

# 5. Limitations and Mitigation Scenarios

## Platform limits (summary)

Source: [Workflows quotas](https://cloud.google.com/workflows/quotas) — verify current values.

| Limit | Typical impact | Mitigation |
| --- | --- | --- |
| **Concurrent executions** | 429 errors at burst | Request quota increase; enable backlogging |
| **Workflow definition size** | Deploy failure | Split into subworkflows |
| **Step expression complexity** | Hard to maintain YAML | Move logic to Cloud Run Functions |
| **No native DAG UI** | Ops visibility vs Airflow | Logging + execution graph; export to monitoring |
| **External HTTP latency** | Long-running chains | Async callbacks; poll pattern |
| **100M+ steps/month** | Custom pricing tier | Contact sales; architect batch in Composer |
| **GCP-only portable definition** | Vendor lock-in | Abstract critical flows; document ports |

## Limitation → mitigation

| Limitation | Scenario | Mitigation |
| --- | --- | --- |
| No complex DAG dependencies | Multi-team batch mesh | Use Composer for core DAGs |
| YAML maintainability at scale | 200+ step workflow | Subworkflows + CI validation |
| Retry on partial parallel failure | Parallel branch | `parallel` exception handling; compensating steps |
| Cold start N/A (managed) | — | Advantage vs self-hosted |
| Limited local data transform | JSON manipulation only | Cloud Run step for Python/SQL |

## When not to use Workflows

| Situation | Better fit |
| --- | --- |
| Nightly 80-task ELT DAG | **Cloud Composer** |
| Need dataset lineage / backfill | **Composer** |
| Complex Python transform in orchestrator | **Dataproc/BQ** + thin Workflows wrapper |
| Kafka-style event log replay | **Pub/Sub + Dataflow** |

## Risk scenarios

### Quota exhaustion (429)

**Symptom:** Eventarc delivers thousands of GCS events simultaneously.  
**Mitigation:** Enable execution backlogging; increase concurrency quota; dedupe at Pub/Sub layer.

### Retry storm on external API

**Symptom:** Step costs multiply.  
**Mitigation:** Cap `max_retries`; circuit-breaker branch; exponential backoff with jitter.

### Secret leakage in logs

**Symptom:** PII in execution I/O.  
**Mitigation:** Redact assign steps; use Secret Manager; restrict log viewer IAM.

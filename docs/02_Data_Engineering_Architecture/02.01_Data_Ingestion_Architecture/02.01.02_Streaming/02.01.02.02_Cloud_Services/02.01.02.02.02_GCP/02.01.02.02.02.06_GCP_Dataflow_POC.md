# GCP Dataflow POC

Proof-of-concept workspace for validating Apache Beam pipelines on Google Cloud Dataflow.

## Objectives

1. Validate streaming and batch SLOs for target throughput and latency.
2. Compare exactly-once vs at-least-once cost/quality trade-offs.
3. Measure worker autoscaling behavior under burst load.
4. Produce FinOps model using [official pricing](https://cloud.google.com/dataflow/pricing).

## Scope

| In scope | Out of scope |
| --- | --- |
| Pub/Sub → BigQuery streaming | Multi-cloud Beam runners |
| GCS batch ETL with FlexRS | Custom shuffle service tuning |
| Python and Java parse benchmarks | Dataproc Spark comparison (see section 02.01.02.06) |
| Streaming Engine SECU billing | Dataflow Prime migration |

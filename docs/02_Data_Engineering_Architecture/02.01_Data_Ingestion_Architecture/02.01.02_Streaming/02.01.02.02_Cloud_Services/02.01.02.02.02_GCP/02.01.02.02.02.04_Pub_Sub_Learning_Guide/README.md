# Google Cloud Pub/Sub Learning Guide

Structured learning path for architects and engineers implementing Pub/Sub in production. Read in order or jump to the module you need.

## Prerequisites

- GCP project with Pub/Sub API enabled
- Familiarity with [Pub/Sub Architecture](../02.01.02.02.02.01_Pub_Sub_Architecture.md)

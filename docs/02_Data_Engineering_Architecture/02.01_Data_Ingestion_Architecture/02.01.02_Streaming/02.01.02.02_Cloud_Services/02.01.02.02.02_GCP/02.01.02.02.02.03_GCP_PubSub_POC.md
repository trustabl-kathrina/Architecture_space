# GCP Pub/Sub POC

Proof-of-concept workspace for validating Pub/Sub against enterprise requirements before platform standardization.

## Objectives

1. Validate throughput and latency SLOs for target message sizes and fan-out.
2. Measure cost per scenario using [official pricing](https://cloud.google.com/pubsub/pricing).
3. Test exactly-once, ordering keys, DLQ, and seek/replay operations.
4. Compare push vs pull vs Dataflow consumption patterns.

## Scope

| In scope | Out of scope |
| --- | --- |
| Publish/subscribe load tests | Multi-cloud Kafka migration |
| Push to Cloud Run | Custom broker tuning |
| Streaming pull consumers | Pub/Sub Lite (deprecated) |
| BigQuery export subscription | Production IAM finalization |

## Success criteria

- [ ] Sustained throughput meets peak × 1.5 headroom
- [ ] p99 latency within business SLO
- [ ] No unbounded backlog under failover test
- [ ] FinOps model approved with batching enforced
- [ ] Security review: IAM, CMEK, VPC-SC if required
